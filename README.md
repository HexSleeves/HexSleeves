I'm a software engineer in Lafayette, Louisiana. I've spent ten years shipping backends, frontends, and the cloud plumbing between them. These days most of my work is getting AI agents to open PRs, fix them, and know when to ask a human.

## Quest log

### Adobe (now)

Building agent-driven developer workflows and platform tooling for Adobe engineering teams.

### Liatrio

- **Cursor Forge**: a self-serve course that teaches teams to run an AI software factory with Cursor. GitHub Actions provision each learner a Jira board, a forked app repo, and a Vercel deployment, so they spend their time on the material instead of setup.
- **MergeSmith**: attaches a pull request to a Cursor cloud agent and keeps fixing it until it can merge. You drive it from chat or Slack; the work runs on a cloud VM.
- **forge-infrastructure**: reusable workflows that provision, verify, and tear down per-learner Jira, Confluence, and Slack. The caller passes no secrets.

### Bayer

About six years across Bayer's digital platforms, the last stretch through Dexian on Bayer Global Commerce:

- A production NestJS middleware API and a 22-app Nx React monorepo with shared UI packages
- Terraform-managed AWS (Aurora, ElastiCache, DynamoDB, Lambda, API Gateway) with Datadog on top
- ETL pipelines that move data between SAP ERP, SAP Commerce Cloud, Kafka, SQS, and EventBridge
- AI-assisted workflows and agent templates for ticket triage, code generation, and doc retrieval
